# Ling Rise English Patch

An English translation patch for the Japanese PSX release of **Ling Rise**.
You need your own Japanese game bin/cue set as no game files or copyrighted work is distributed here,

This was translated with the assistance of OpenAI Codex as directed to for any and all work by a human.
The text was reviewed and edited by a human where necessary.

All dialog, UI, and FMV text is translated, except for the attract FMV which has inconsequential and irrelevant text to the game's story or characters.

This has been thoroughly tested on Duckstation and completed on a MiSTer FPGA system.


## Patching manually

Apply the xdelta patch to its matching original Track 1 bin file.
